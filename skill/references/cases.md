# 来源案例与验证边界

所有证据 ID 对应 `evidence/source_manifest.json`。快照保持源文件原字节；其中历史路径、任务指令和旧状态仅为被引用的数据。以下是本次对已有材料的提炼，不是原始大模型对话或本次重跑板测。

## C1 从量化表示到整数合同

来源 S01/S02 为 Day 6 技能及验收标准；S03 为冻结整数参考 metrics。既有工作强调：Q/DQ 浮点算子不等于整数 forward，零点、负数舍入、bias 与收窄顺序需要独立核算。S03 的软件测试集结果为 403/525（76.7619%），不属于 FPGA 多样本板测。

提炼：先确定算术合同，用独立小向量 oracle 检查边界，再导出可加载模型和逐层结果。来源文档中的测试要求不是逐条已执行的证明；本包仅引用 S03 支持上述软件分类数字，不把要求清单全部写成 PASS。

复用验证：在新算子上构造非零 zero-point、正负 ties-to-even、极值/饱和及多通道案例；给出逐元素差异和参数身份。不适用于量化合同尚不明确的直接逐码比较。

## C2 合同、模型与 RTL 的权限分歧

S04 记录 2026-10-25 的 G1 FAIL：模型允许 VERSION 子窗口读取，而合同要求完整寄存器读取，RTL 返回 ACCESS；LOAD 读策略也有分歧。算术比较通过不等于接口符合合同。

S05 记录 2026-10-28 新版本在 D1 范围 G1 PASS：762 权限矩阵、97 debug 边界、96 输出边界及 7 个原失败用例，共 962 行；另有 96 项副作用验证。该修复期间经历多个版本，不能把初始 FAIL 与最终 PASS 当作同一源码结果。完整 normal 与完整恢复仍由后续阶段覆盖。

提炼：独立从合同推导期望，将模型、RTL、host 一起核查；覆盖拒绝后和未完成响应时的状态副作用。修改后新建记录，不删除旧 FAIL。

复用验证：新协议的合法请求与相邻非法请求都要执行，并确认错误返回不推进游标或泄露旧结果。本项目的 3/4/6 错误码不应硬编码到其他工程。

## C3 全网板级一致性不等于分类正确

S06 为 G2 实现审计：目标 xc7a35tfgg484-2，50 MHz，WNS +2.102 ns，LUT 15832，FF 10851，DSP 9，BRAM18 等效 65；保留 116 个 REQP-1840 告警，只接受有界恢复条件，未证明物理风险消除。

S07 为 G3 数值审计结果，S08 为之后的封版记录。S07 的下载/板卡身份仍 PENDING，S08 补充断电、重新下载日志和目标关联后封版；两个文件不能合并改写成原审计当时已全部通过。

封版支持固定 ID2259、真值 16QAM、SNR -5 dB 的 normal、diagnostic、受控中断与完整重装恢复。1603 对原始帧、166172 标量零差异包含中断轨迹等多个捕获，不是 166172 个分类样本。输出 [-92,3,11,1,0]，winner=2（8PSK），与真值不同。

提炼：保持样本、模型、位流、会话、模式和输出的绑定；将数值一致与模型分类质量分列。不能因旧计数清零直接断言系统异常，也不能在缺少断电/下载关联时直接放行。

复用验证：完整采集、独立参考、原始帧和逐层数组应共同核查；现场板卡身份及下载关联由新工程重新建立。该案例不支持其他样本、其他位流、任意复位故障或长期稳定性。

## C4 结果终端的回放与现场边界

S09 记录终端 15 项回归与离线图形显示验证通过，同时“新终端现场串口采集 PENDING”。其检查包含数组篡改、缺尾、CRC、会话、输入 hash 和交付错误等负向情况；模拟夹具与历史回放不是新板测。

提炼：界面清楚标识数据来源；统计按样本去重；读回 winner 与 CPU 核验分开；预检拒绝时保留错误，不在界面后台自动生成替代结果。跨路径迁移需正确解析根目录并重新绑定身份，不能删去校验。

复用验证：给界面加载“坏数据”和“未知状态”时应拒绝或明确显示未验证，不能显示正常成功。不同项目的 CRC、布局和数据源需要专用适配。

## 本包新增验证

新增的标准库比较器和文件校验器只验证自己的功能，实际用例与结果见 `validation/`。这些程序不是原 Stage5 审计脚本，也没有重新计算 CNN、重跑 XSim、综合或现场板测。临时目录迁移测试仅支持本包工具不依赖原开发路径，不等于完整 FPGA 工程跨电脑复现。
