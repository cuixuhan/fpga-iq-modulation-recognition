# 整数合同与边界

## 在产生测试结果前固定

记录每个张量的 shape、轴顺序、整数范围、scale、zero-point；每层的权重轴、bias 网格、累加位宽、乘积位宽、M/shift、舍入、饱和、ReLU、padding 和 Argmax 平局规则。记录合同版本及模型/输入 hash。相同标签或相同 shape 不意味着相同合同。

本项目是 W8A8、权重逐输出通道对称量化、激活带零点。居中输入使用 9 位；累加与 bias 为 32 位；重标定乘积为 64 位。**这些是案例设置，不是所有 FPGA 工程的默认正确配置。**应从新模型的范围推导位宽。

## 易错点与检查方法

| 易错点 | 最小检查 | 不可接受的处理 |
|---|---|---|
| 非零输入零点 | 当 Zx=-4，padding 应填 -4，居中值为 0；整数码 0 的居中值为 4 | 将编码 0 当实数零跳过 |
| 负数 ties-to-even | -5/2=-2.5 应到 -2；-7/2=-3.5 应到 -4；正数 5/2→2、7/2→4 | 用单一“加半右移”代替合同且不测正负奇偶边界 |
| 收窄顺序 | 宽位乘加后检查范围，再饱和收窄 | 先 cast 到 INT8/INT32 再检查溢出 |
| bias | 每个输出恰好加入一次 | 每个乘法重复加 bias |
| GAP | 先按合同居中求和，再执行一次比例重标定 | 逐点舍入后求平均且声称等价 |
| MaxPool | 相同正 scale 网格可比较整数码 | 在不同量化网格直接比大小 |
| Linear 和 Argmax | 明确输出是否 ReLU，平局取最先还是最后 | 依赖语言库默认规则而不固化合同 |

独立 oracle 用 Python 宽整数或与生产路径不同的实现核算。不要共享被测 requantization helper，否则两边可能同时带错。先测手算小张量、通道混合、padding、极值、饱和和非法参数，再测试真实层及全网。

## 分类与数值一致性

每个样本保存 `sample_id / true_label / snr / reference_prediction / hardware_prediction`。参考预测与硬件预测相同，只说明分类输出一致；若要证明完整数值一致，应核对所声明的全部张量，不能由 winner 相等外推。分类准确率按真实标签独立计算；同一输入的 normal/diagnostic/recovery 不计成三个不同分类样本。

## 失效条件

量化或模型变更、I/Q 轴交换、输入预处理变更、有符号解码错误、布局改变以及未检查的溢出均使旧对照失效。对于浮点误差、不同算法近似或容差比较，应另立阈值和工具；随包 CSV 比较器仅支持同合同的精确整数相等，不实现 CNN oracle。
